# C7 数据截图说明

> 本目录存放 C7 的数据截图与操作指引。

---

## 一、截图分两类

| 类别 | 说明 | 状态 |
|------|------|------|
| **A. 排版渲染图** | 文章真实渲染效果，不依赖发布 | ✅ **已生成**（见下方清单） |
| **B. 发布后数据图** | 文章真实发布后的后台数据 | ⏳ 需发布后截取，步骤见 **`发布后数据截图操作指引.md`** |

---

---

## 三、截图规范

1. 格式：PNG/JPG。
2. 命名：编号 + 文章序号（如 `03_文章1_24小时数据.png`）。
3. 数据截图要清晰显示数字和查询日期。
4. 建议同时截取后台的数据趋势曲线图。
5. B 类数字必须真实，来自公众号后台或"订阅号助手"App，不要 P 图或编造。

## 四、截图工具

| 平台 | 工具/快捷键 |
|------|-------------|
| Windows | Win+Shift+S |
| Mac | Cmd+Shift+4 |
| 安卓手机 | 电源键 + 音量下 |
| 苹果手机 | 电源键 + 音量上 |
| 公众号手机管理 | 微信官方"订阅号助手"App |
