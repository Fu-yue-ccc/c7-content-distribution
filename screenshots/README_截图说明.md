## 截图规范

1. 格式：PNG/JPG
2. 命名：按编号+文章序号
3. 数据截图要清晰显示数字
4. 建议同时截取数据趋势图（后台有曲线图）

## 截图工具

| 平台 | 工具/快捷键 |
|------|-------------|
| Windows | Win+Shift+S |
| Mac | Cmd+Shift+4 |
| 手机 | 系统截图（安卓电源键+音量下，苹果电源+音量上） |
